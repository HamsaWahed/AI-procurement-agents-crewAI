# 🤖 AI Agents for Procurement Automation using CrewAI

## 📌 Overview

This project demonstrates how to use **AI Agents (CrewAI)** to automate a procurement workflow — from searching products online to generating a structured report.

The system simulates a real-world procurement process for **coffee machines**, including:

* Product discovery
* Price comparison
* Recommendation generation
* Automated report creation

---

## 🚀 Features

* 🔍 Intelligent product search across multiple platforms
* 📊 Price comparison and filtering
* 🧠 AI-driven recommendations
* 📝 Auto-generated HTML report
* ⚡ Multi-agent orchestration using CrewAI

## ⚙️ How It Works

The system is built using multiple AI agents collaborating together:

1. **Search Agent** → Finds products online
2. **Filtering Agent** → Keeps relevant results
3. **Analysis Agent** → Compares prices & specs
4. **Reporting Agent** → Generates final report
